The Vaccine Management & Tracking System is a web-based application designed to digitally manage and monitor the vaccination process, including appointment scheduling, status tracking, and administrative oversight. The system addresses challenges associated with manual vaccine management such as scheduling delays, lack of real-time tracking, and inefficient communication between vaccination centre sand users.
This application enables registered users to securely book vaccination appointments and track their vaccination status through an intuitive web interface. To ensure system security and data integrity, the platform implements JWT-based authentication with role-based access control, providing separate login mechanisms for users and administrators.
Administrators are provided with a centralized dashboard that allows them to manage vaccine bookings, monitor vaccination progress, and analyse system data effectively. Additionally, the system incorporates automated email notification services to send reminders for upcoming vaccination appointments, improving user compliance and reducing missed schedules.
Developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js), the Vaccine Management & Tracking System is scalable, secure, and suitable for real-world healthcare environments. This Software Requirement Specification (SRS) document provides a complete and structured overview of the system requirements necessary for the design, development, and implementation of the application.
